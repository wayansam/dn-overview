# DN Overview

Dragon Nest Sea utility tools, live at https://wayansam.github.io/dn-overview/.

Built with React, Ant Design and Redux Toolkit, using [Vite](https://vite.dev/).
Requires Node.js 20.19+ or 22.12+.

## Available Scripts

In the project directory, you can run:

### `npm start`

Runs the app in development mode at [http://localhost:3000/dn-overview/](http://localhost:3000/dn-overview/).\
The page updates instantly when you make edits.

### `npm test`

Runs the tests with [Vitest](https://vitest.dev/) in watch mode. Use `npx vitest run` for a single run.

### `npm run lint`

Runs ESLint over `src`. Any warning fails the check.

### `npm run build`

Type-checks the project, then builds it for production into the `build` folder.

### `npm run preview`

Serves the production build locally, to check it before deploying.

### `npm run deploy`

Builds the app and publishes the `build` folder to GitHub Pages.
